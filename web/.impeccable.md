# Rewall web

## Design Context

### Users

Developers and crypto-native people who keep API keys, notes and authenticator seeds under an ENS name they
own. They sit at a desk, in an editor-adjacent context, and read the dashboard the way they read a terminal.

### Brand Personality

Quiet, precise, sovereign. The interface never sells itself. Nothing on screen is decoration or reassurance.

### Aesthetic Direction

Dark, near-monochrome, hairline borders, no shadows. Manrope for UI, Lexend Deca 200 for the few display
lines, Ubuntu Mono for anything that is an address, a name or a count. A single signature texture, the
animated Bayer dither in the home banner, white on dark. Anti-references are crypto neon, glassmorphism,
gradient fills and mascot illustrations.

### Design Principles

1. Bare minimum on screen. A label that restates what is already visible is deleted, not reworded.
2. Borders, never shadows. One radius for containers and controls, one smaller radius for chips.
3. Opacity and color only in motion. No scale, no transform, no bounce.
4. Icons are stroke drawings on a 48 grid from Arcticons. Never a text glyph standing in for an icon.
5. Never state something the chain has not been read for.
